Desktop Pet 간단 버전

실행:
  Run Desktop Pet.vbs 를 더블클릭하면 콘솔 창 없이 캐릭터가 뜹니다.
  Run Desktop Pet.cmd 는 문제가 생겼을 때 확인용으로만 사용하세요.

사용:
  - 캐릭터를 드래그하면 위치를 옮길 수 있습니다.
  - 캐릭터를 우클릭하면 이미지 변경, 기본 캐릭터로 되돌리기, 종료 메뉴가 나옵니다.
  - 이미지 변경으로 PNG/JPG/GIF/BMP 파일을 선택하면 다음 실행 때도 그 캐릭터가 유지됩니다.

참고:
  - 항상 위에 뜨도록 설정되어 있습니다.
  - 선택한 이미지는 config\custom-pet.png 로 복사되어 원본 파일을 옮겨도 계속 사용할 수 있습니다.
